# 🙌 Contributing to Chaos Ward

Thanks for wanting to help! Chaos Ward is maintained by **moemor**, who has the final say on what goes into the project.

## 🐛 Reporting bugs
1. Update to the latest version first.
2. In Chaos Ward open **Settings → Diagnostic package → Create**.
3. Open a [bug report](../../issues/new?template=bug_report.yml), describe what happened and attach the ZIP file from your desktop.

## 💡 Ideas
Open a [feature request](../../issues/new?template=feature_request.yml). Please describe the crafting situation you have in mind.

## 🔧 Pull requests
* Talk about bigger changes in an issue first.
* Keep the safety rule: Chaos Ward never sends keys or clicks and never reads game memory. Changes that break this rule will not be accepted.
* Run `python3 tools/check_ahk.py app/ChaosWard.ahk` before you submit.
* By submitting a contribution you agree that it is licensed to moemor under the same terms as the project and that moemor may also use, relicense and distribute it in future versions of Chaos Ward, including under other licenses.

## 🏷️ Name and logo
Forks must not use the name "Chaos Ward" or its logo, see the README.
